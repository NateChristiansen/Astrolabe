# Astrolabe

Shared notes, saved work, and a shell guard for agents while Astrolabe is on.

This plugin requires the matching Astrolabe program on each machine. Follow the [installation guide](https://github.com/NateChristiansen/Astrolabe/blob/v0.5.0/plugin/README.md) for prebuilt downloads, notes setup, migration, and the fresh-session check. Install the program before enabling the plugin; the plugin does not download it in a hook.

Your notes stay in your own Git repo. The program's machine switch controls whether the hooks do work. Installing the plugin alone does not prove that its hooks run or that the shell guard is active.
